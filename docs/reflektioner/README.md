# Individuella reflektioner

Här samlas varje students individuella reflektion. **Ingen individuell reflektion är inlämnad ännu** (2026-11-13, sprint 1).

## Så gör du

1. Kopiera [`MALL.md`](MALL.md) till en ny fil med ditt namn, t.ex. `leo-spenner.md`.
2. Lämna `MALL.md` orörd.
3. Skriv i jag-form och koppla till dina issues, PR:er och retron.
4. Uppdatera reflektionen efter varje sprint.

Reflektionen är en del av examinationen och bedöms individuellt.
